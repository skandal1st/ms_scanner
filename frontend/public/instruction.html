S skandata

Инструкция по работе с сервисом «Скандата»

Приёмка, отгрузка, списание и проверка маркированных товаров в одном окне. Коды маркировки проверяются и проводятся в «Честном Знаке», документы и позиции — в «МойСклад».

Инструкция предназначена для кладовщика и администратора. Все действия выполняются в браузере — установка программ не требуется (кроме плагина КриптоПро для входа в «Честный Знак», см. ниже).

1Запуск

Сервис можно открыть двумя способами:

  1. Из каталога решений МойСклад (основной способ). Установите решение «Скандата» на свой аккаунт. Внутри МойСклада появится вкладка приложения — на ней краткое приветствие, настройки и кнопки «Начать приёмку» / «Начать отгрузку». По кнопке рабочий экран открывается в новой вкладке браузера (так USB-сканеру не мешает потеря фокуса внутри окна МойСклада).
  2. Напрямую по адресу https://skandata.ru/ — вход через МойСклад.
Заметка. После первого запуска из каталога подключение к МойСкладу уже активно — вводить токены вручную не нужно.

2Настройка (раздел «Настройки»)

Перед первой работой откройте Настройки и выполните подключения.

2.1 МойСклад

При запуске из каталога решений подключение устанавливается автоматически. Статус подключения и название аккаунта показаны в разделе. Кнопка «Отвязать МойСклад» отключает интеграцию (данные документов при этом сохраняются).

2.2 Честный Знак

Вход выполняется по усиленной квалифицированной электронной подписи (УКЭП) через плагин КриптоПро ЭЦП Browser plug-in:

  1. Установите плагин КриптоПро (если ещё не установлен) и подключите носитель с подписью.
  2. Нажмите «Войти в Честный Знак» — сервис запросит подпись, приватный ключ остаётся в вашем браузере и никуда не передаётся.
  3. После входа отображается срок действия токена и субъект сертификата.

ИНН участника оборота определяется из сертификата автоматически; при необходимости его можно указать вручную (нужен для документов списания).

2.3 Товарные группы

Отметьте товарные группы, с которыми работаете (табак, обувь, вода и т. д.). От этого зависит корректная проверка кодов в «Честном Знаке».

2.4 Сканер

В разделе Настройки → Сканер выберите способ ввода кодов:

  • USB-сканер (клавиатура) — режим по умолчанию. Сканер работает как клавиатура: просто отсканируйте код в поле ввода, установка ничего не требует. Подходит большинству USB-сканеров «из коробки».
  • COM-порт (Web Serial API) — если сканер подключён как виртуальный COM-порт (USB-CDC / RS-232). Работает только в браузерах Chrome или Edge по HTTPS. Нажмите «Подключить COM-порт» и выберите порт сканера в диалоге браузера — порт запоминается, при следующих запусках подключение автоматическое.

Настройки сканера для режима COM-порт

Переключите сканер в режим Virtual COM Port (USB-CDC) и задайте параметры порта (обычно настраивается сервисными штрих-кодами из инструкции к вашей модели сканера):

ПараметрЗначение
Скорость (baud rate)9600
Биты данных (data bits)8
Чётность (parity)нет (none)
Стоп-биты (stop bits)1
Управление потоком (flow control)нет (none)
Окончание строки (суффикс)CR, LF или CR+LF (перевод строки после каждого кода)
Разделитель групп GS1 (FNC1 / GS)включён: символ GS (0x1D) или подменный 0xF8 — сервис распознаёт оба (0xF8 — типовая настройка «под 1С»)

Коротко: 9600, 8-N-1, без управления потоком, суффикс CR/LF, передача GS-разделителя включена. Разделитель групп обязателен — без него коды GS1 DataMatrix (с несколькими полями, напр. GTIN + серийный номер + срок годности) склеятся и не пройдут проверку.

Внимание. Если после подключения появляется «COM-порт занят другой программой» — закройте другие вкладки/окна приложения и программы, использующие сканер (например, «1С» или тест-утилиту производителя), и подключитесь заново. Порт может держать только одна программа.

3Приёмка товаров (раздел «Приёмка»)

Приёмка выполняется на основании УПД (универсального передаточного документа).

  1. Выберите товарную группу и поступление из МойСклада (поиск по названию).
  2. Нажмите «Загрузить УПД» и выберите XML-файл УПД (формат ФНС 5.03). Сервис распознает позиции и коды маркировки, в том числе короба и блоки (агрегаты автоматически разворачиваются на штучные коды).
  3. Товары сопоставляются с позициями поступления по GTIN. Если какой-то товар не определился — сопоставьте его вручную в панели подбора (поиск по каталогу МойСклада).
  4. Нажмите «Отправить приёмку в МС». Коды маркировки запишутся в позиции выбранного поступления. Дождитесь статуса «Принято».
Заметка. Если поступление не выбрано, приёмка работает в режиме только проверки — коды проверяются, но в МойСклад не записываются.

4Отгрузка товаров (раздел «Отгрузка»)

  1. Выберите отгрузку из МойСклада. Если у документа есть план, он отобразится таблицей прогресса по товарам.
  2. Сканируйте коды маркировки USB-сканером (работает как клавиатура) или вводите вручную. Каждый код сразу отправляется на проверку; результат подсвечивается цветом, звучит сигнал.
    • Короба (SSCC) можно раскрыть на штучные коды или отгрузить целиком.
    • Немаркированный товар добавляется сканированием обычного штрихкода (EAN).
    • Коды сверх плана отмечаются отдельно и не мешают отправке.
  3. Нажмите «Отгрузить». Коды запишутся в позиции отгрузки в МойСкладе. Итог можно выгрузить в XLSX.

Подсказки при отгрузке: если владелец кода в «Честном Знаке» не совпадает с вашим ИНН — код помечается «Чужой владелец» (предупреждение, отгрузку не блокирует).

5Списание — вывод из оборота (раздел «Списание»)

Списание выводит коды маркировки из оборота через «Честный Знак». МойСклад в этом потоке не участвует.

  1. Соберите коды (сканированием или списком) и выберите причину вывода из оборота (порча, собственные нужды, демонстрационные образцы и др.).
  2. При необходимости укажите основание (номер и дату первичного документа).
  3. Нажмите отправку и подпишите документ электронной подписью. Приватный ключ остаётся в браузере.
  4. Дождитесь статуса «Списано». При ошибке сервис покажет причину.

6Проверка марок (раздел «Проверка»)

Отсканируйте код или вставьте список кодов (по одному в строке), чтобы узнать статус, владельца, производителя и товар без изменения каких-либо документов. Результат проверки можно выгрузить в CSV.

7Техническая поддержка

Если что-то не работает или непонятно:

  1. Откройте раздел «Помощь».
  2. Нажмите «Написать в техподдержку».
  3. Выберите раздел, укажите тему и опишите проблему (по возможности — номер документа и шаг, на котором возникла ошибка).
  4. Отправьте обращение. Оно поступит напрямую в нашу поддержку; ответ придёт на электронную почту, привязанную к вашей учётной записи.

Запасной канал связи — электронная почта поддержки, указанная в форме обращения.

8Частые вопросы

Сканер не срабатывает.

Убедитесь, что рабочий экран открыт в отдельной вкладке (а не внутри окна МойСклада) и что курсор находится в области сканирования. Для режима COM-порт проверьте параметры сканера (см. §2.4) и что порт не занят другой программой.

«Войдите в Честный Знак».

Токен «Честного Знака» истёк — повторно войдите в разделе «Настройки» (для входа нужна свежая электронная подпись).

Товар не определился по коду.

Сопоставьте GTIN с товаром вручную в панели подбора — сопоставление запоминается для последующих документов.

Коды не записались в МойСклад.

Проверьте, что выбран документ МойСклада и что у решения есть необходимые права (переустановите решение из каталога, если недавно обновлялись права доступа). При повторении — напишите в техподдержку.
