# Подписки маркетплейса МойСклад

Тариф общий для аккаунта, всех юрлиц и складов. Цены: Базовый — 5000 ₽/мес.
(без ТСД), Склад — 7000 ₽/мес. (5 ТСД), Безлимит — 10000 ₽/мес.
Покупка и продление происходят в МойСклад. Издание `ms_lite/full` остаётся отдельным
ограничением модулей; покупка тарифа с ТСД не меняет издание.

ID тарифов заданы по умолчанию в конфигурации и Docker Compose:

| Тариф | ID | Лимит ТСД |
|---|---|---|
| Базовый | `5436912b-e322-454a-a48e-ed38e2cca4fa` | 0 |
| Склад | `f9d60a1c-43f4-4151-985a-f653299856a2` | 5 |
| Безлимит | `79af0218-9153-4401-ad24-c39ce0e88ac7` | Без ограничений |

## Настройка и выпуск

1. Три тарифа созданы в кабинете разработчика МС; соответствия приведены выше.
2. При использовании другого решения переопределить UUID в `.env`: `MOYSKLAD_TARIFF_BASIC_ID`,
   `MOYSKLAD_TARIFF_TSD5_ID`, `MOYSKLAD_TARIFF_UNLIMITED_ID`.
   ID должны быть различными. Названия тарифов не используются для выдачи прав.
3. Выполнить миграции и пересоздать backend/worker/frontend с обновлённым окружением.
4. Синхронизировать подписки уже установленных аккаунтов (UUID решения Скандата:
   `8fa85fbe-eae4-4445-a431-212f735ee9e5`, не `MOYSKLAD_APP_UID`):

   ```bash
   docker compose -f docker-compose.prod.yml run --rm backend python -m app.sync_subscriptions --app-id 8fa85fbe-eae4-4445-a431-212f735ee9e5
   ```

   Команда читает статус через Vendor API и обновляет локальную подписку.
   Ошибка внешнего API прерывает запуск; команду можно повторить.
   До синхронизации старые аккаунты маркетплейса блокируются для операций,
   поэтому выполнять выпуск в согласованное окно обслуживания.
5. Проверить на тестовом аккаунте установку, смену тарифа, автопродление,
   приостановку и возобновление. Изменение XML-дескриптора не требуется.

## Правила доступа

- Считаются активные привязанные ТСД, даже выключенные. Отключение в настройках
  освобождает место. История и сканы сохраняются.
- QR не резервирует место. При обмене QR лимит повторно проверяется под блокировкой
  строки аккаунта PostgreSQL, исключая подключение шестого устройства при гонке.
- При понижении до 5 ТСД и наличии большего количества работа терминалов
  приостанавливается до отключения лишних. Администратор выбирает, какие оставить.
- Базовый тариф блокирует ранее подключённые ТСД, но разрешает работу с компьютера.
- Истечение срока, деактивация и неизвестный ID тарифа блокируют операции.
  Настройки, список устройств и поддержка остаются доступны.
- Проверка ТСД общая для отгрузки, приёмки, инвентаризации и heartbeat WebSocket.
- `Install`, `Resume`, `TariffChanged`, `Autoprolongation` сохраняют подписку.
  Отсутствие `access` в уведомлении не удаляет действующий токен МС.
- Пробный период даёт возможности того тарифа, ID которого приходит от МС.
- Аккаунты вне маркетплейса сохраняют прежний доступ. Миграция помечает аккаунты
  издания `ms_lite` с `moysklad_account_id` как управляемые маркетплейсом.
  Синхронизация проверяет все аккаунты с ID МС и помечает остальные установки,
  если Vendor API подтверждает наличие подписки; OAuth без установки не блокируется.

При пропущенном callback повторить синхронизацию. Изменение тарифа из браузера
не предусмотрено: источником прав является подписка МС.
