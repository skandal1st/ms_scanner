# Статус отгрузки после передачи

В настройках текущего юрлица выберите статус МойСклада или «Не менять статус» (по умолчанию). Применяется только к отгрузке demand, а не заказу покупателя или приёмке.

При постановке передачи в очередь выбранный UUID фиксируется в Document.upd_meta.shipment_sent_state_id. Воркер проверяет доступность статуса перед записью и обновляет state отдельным PUT после успешной записи всех trackingCodes. Любой отказ записи марок оставляет статус МС без изменения. Ошибка смены статуса возвращает сессию в черновик с сообщением о переданных марках; повторная отправка читает сохранённые trackingCodes и продолжает без повторного добавления.

Миграция20261005_03 добавляет nullableUUID в organization_profiles; старые настройки автоматически означают «не менять». Разрешения дескриптора demand read/update остаются прежними.

Проверка:190 тестов прошли,1Redis-тест пропущен; миграции на изолированном PostgreSQL и TypeScript/Vite сборка прошли. UI сохранение и восстановление проверены на синтетическом сервере. Реальные статусы складских документов для теста не менялись.
