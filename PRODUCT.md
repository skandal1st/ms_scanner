# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

Кладовщики склада маркированных товаров (табак, вода и др. товарные группы
Честного Знака). Работают на десктопе/ноутбуке с проводным USB-сканером,
в условиях склада (яркий свет, работа стоя, поток из сотен-тысяч кодов за
смену). Один аккаунт = один склад (мультиарендность: у каждого пользователя
свои токены МойСклад и Честный Знак). Пиковая нагрузка — до ~10 000 сканов
за день.

## Product Purpose

Веб-приложение «в одном окне» для приёмки, отгрузки и списания маркированных
товаров. Снимает с кладовщика ручную сверку кодов маркировки: сканирует КМ,
проверяет их в Честном Знаке, пишет trackingCodes в документы МойСклад
(приёмка по УПД, отгрузка) и выводит из оборота (списание). Успех — коды
уходят в МойСклад/ЧЗ без ошибок, кладовщик не сверяет марки вручную.

## Positioning

Единственная точка, где сходятся сканер, МойСклад (Vendor API, чтение
документов + запись trackingCodes) и Честный Знак (проверка КМ, ввод/вывод
из оборота через УКЭП). Живёт внутри каталога решений МойСклад: iframe-лаунчер
внутри МС + рабочий поток в отдельной вкладке (USB-сканеру нужен фокус, iframe
его теряет). Приватный ключ УКЭП остаётся в браузере клиента (CryptoPro CSP) —
подпись документов ЧЗ идёт client-side.

## Operating Context

- **Потоки по типу документа**: приёмка (`supply`, импорт УПД ФНС 5.03),
  отгрузка (`demand`, сканирование), списание (`loss`, вывод из оборота ЧЗ).
- **Сквозной поток**: скан → парсинг (обычный КМ / SSCC-короб) → асинхронная
  проверка в ЧЗ (Celery) → WS-обновление статуса + звуковой сигнал.
- **Статусы сканов функциональны**: valid / invalid / duplicate / overflow
  (сверх плана) / unknown_product (нужно сопоставить товар) / used_in_other_doc /
  withdrawn (выведен из оборота) / owner-mismatch (чужой владелец марки). Их
  надо считывать мгновенно на потоке.
- **План сборки** по GTIN: прогресс N/M + перевыполнение.
- **УКЭП round-trip** для ЧЗ: challenge → подпись в CryptoPro плагине → login.

## Capabilities and Constraints

- React 18 + Vite + TS SPA, без CSS-фреймворка (стили — `styles/uikit.css` +
  `styles/app.css` на CSS-переменных + inline). Состояние: Zustand (скан-сессия)
  + React Query (серверные данные). WebSocket для статусов сканов.
- Бэкенд FastAPI + Celery + Postgres + Redis. МС — Vendor API. ЧЗ — True API.
- Роуты: `/shipment` `/acceptance` `/writeoff` `/check` `/settings` `/login`
  `/ms` (лаунчер) `/launch` (обмен токена).
- Интерфейс на **русском** (конечный пользователь — кладовщик). Идентификаторы
  кодов — моноширинный шрифт.
- CryptoPro плагин подключается из `public/cadesplugin_api.js` (для real-ЧЗ).

## Brand Commitments

- Имя латиницей/продукт: сканер маркировки для МойСклад (домен `skandata.ru`).
- **Пинн от пользователя (2026-08-22)**: визуальный язык — «вдохновлённый новым
  МойСклад, но со своей айдентикой». Новый МС — плоский, азурно-синий, светлый
  фон, белые карточки, плоские таблицы со статус-пилюлями, чипы-фильтры.
  Приложение должно гармонировать с МС (встроенность), но читаться как отдельный
  продукт (собственный акцент, своя шапка). Старый скевоморфный UI-кит МС
  (HelveticaNeueCyr, градиентные кнопки, оранжевый `#cc420c`) — устарел, заменяем.
- Шрифт HelveticaNeueCyr уже в репозитории (`public/uikit/fonts`, самохост) —
  рабочий нейтральный гротеск, оставляем как основной UI-face.
- **Функциональная цветовая индикация статусов сканов сохраняется** (в палитре
  МС-семейства): зелёный/оранжевый/красный/серый.

## Product Principles

1. **Скорость и считываемость на потоке важнее выразительности.** Кладовщик
   сканирует сотни кодов — статус каждого должен читаться за доли секунды.
2. **Встроенность в МойСклад — часть продукта.** Визуально не должно быть шва
   между МС и приложением, но айдентика — собственная.
3. **Асинхронность скрыта от пользователя.** API-роуты не ходят в ЧЗ/МС
   синхронно; отклик мгновенный, устойчивость к таймаутам внешних систем.
4. **Ошибки — на русском, с причиной и способом исправить** (видит кладовщик).
5. **Секреты и приватный ключ — не наружу.** УКЭП в браузере, токены под Fernet.

## Accessibility & Inclusion

Рабочий инструмент под яркий свет склада: высокий контраст текста и статусов,
крупные интерактивные цели, звуковое подтверждение сканов (в т.ч. отдельный
сигнал на несопоставленную позицию). Интерфейс — на русском.
