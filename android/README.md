# Скандата ТСД для Android

Версия 0.1.2 использует обновлённый список заказов: номер и дата, полное имя
контрагента и статус, компактная информация об отгрузках. В настройках фильтров
можно выбирать несколько статусов заказа. Интерфейс загружается с сервера;
эти изменения требуют обновления веб-версии Скандаты.

Приложение обрабатывает QR отгрузки `skandata:<UUID>` и открывает выбранный
документ в приложении. Эти QR можно также считать в поле «Сканировать QR» PWA.
Скачать текущий APK: https://skandata.ru/downloads/skandata-tsd.apk.

Тестовое Android-приложение открывает рабочую версию https://skandata.ru/tsd
в WebView без адресной строки. Требуется Android 8.0 или новее, актуальный
Android System WebView и интернет. Сканер должен передавать данные как ввод
с клавиатуры (с завершающим Enter); интеграция с SDK конкретного ТСД пока не добавлена.

Привязка хранится отдельно от Chrome/PWA: после установки откройте новый QR
подключения в настройках и отсканируйте его в приложении. Удаление приложения
или очистка его данных удаляет привязку. Обновление APK с той же подписью её сохраняет.
Сканы отправляются на сервер; офлайн-сборка не реализована.

Откройте папку `android` в Android Studio, дождитесь Gradle Sync и выберите
Build → Generate App Bundles or APKs → Generate APKs. Из терминала:

```powershell
./gradlew.bat assembleDebug
./gradlew.bat lintDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`. Это тестовая сборка,
подписанная debug-ключом. Для постоянного распространения нужен отдельный
release-ключ, который не следует добавлять в Git.
