# Схема исходящего УПД 5.03

`ON_NSCHFDOPPR_1_997_01_05_03_05.xsd` — официальный файл ФНС,
скачан 23.10.2026 без изменений из архива «xsd-схема, действующая с 01.01.2026».

Источник: https://www.nalog.gov.ru/rn77/about_fts/docs/14414412/
Архив: https://www.nalog.gov.ru/html/sites/www.new.nalog.ru/files/about_fts/docs/xsd/14414412.zip

Генератор проверяет XSD и дополнительно проверяет итоги, реквизиты, дубли кодов
и обязательные признаки в имени файла по приказу 970 (редакция 1032).
XSD содержит расширения Schematron с `usch:iif`: lxml не исполняет эти расширения.
Проверка XSD не заменяет проверки оператора ЭДО при импорте/подписании.

Первая версия: рубли, российские ЮЛ и ИП, руководитель/ИП без доверенности,
без начисления акциза. Подпись и отправка покупателю не выполняются.
Грузоотправитель совпадает с продавцом, грузополучатель — с покупателем;
адрес доставки берётся из отгрузки, при отсутствии — адрес покупателя.
Отдельные грузополучатели/отправители, подразделения, услуги, комплекты,
алкоголь и строки с декларациями ГТД/РНПТ блокируются, чтобы не потерять реквизиты.
