# Режимы ТСД

После подключения терминал показывает доступные режимы: отгрузка, приёмка,
инвентаризация. Права назначаются чекбоксами в настройках при подключении и
для каждого активного ТСД. Сервер проверяет права на каждом запросе; меню
обновляется в течение 10 секунд. Существующие ТСД сохраняют доступ к отгрузке.

## Приёмка

Загрузите XML на ПК. В блоке «Сверка приёмки на ТСД» можно подготовить сверку
и выбрать склад для XML без привязанного поступления МС. На терминале откройте
режим приёмки и документ. Сверка хранится отдельно от импортированных марок:
загрузка XML не увеличивает фактически принятое количество. Новые XML сохраняют
все строки, включая несопоставленные и товары без марок. Для старых загрузок
используется сохранённый план документа; для полного состава загрузите XML снова.
Если XML изменился после начала сверки, повторное открытие приёмки создаёт новую
сверку; предыдущие сканы сохраняются в истории и больше не изменяются.

GTIN определяет позицию автоматически. При неоднозначности выберите её явно.
Для товаров без штрихкода можно добавить количество вручную. Блок с неизвестным
количеством не засчитывается как одна банка: его нужно сверить поштучно или
ввести количество. SSCC требует проверки содержимого, сам код количества не задаёт.

## Инвентаризация

На ПК в разделе «Инвентаризация» или на ТСД выберите склад и статусы отгрузок,
товары которых физически остаются на складе. Снимок готовится в фоновом задании.
Выгружаются товары и модификации, включая архивные, нулевые и зарезервированные
остатки. Охват — весь склад по всем юрлицам аккаунта МС, как в отчёте остатков.

Ожидаемое количество = остаток МС (`stock`, а не доступное после резерва)
+ позиции проведённых отгрузок выбранного склада и статусов. Непроведённые
отгрузки не прибавляются. Снимок фиксируется для сессии; повторный запуск задания
не заменяет уже открытый план. Новые движения после выгрузки не обновляют его.

Выберите бренд (группу товаров МС), пересчитайте позиции и нажмите «Бренд проверен».
Можно работать несколькими терминалами. Уникальная марка учитывается один раз,
обычные штрихкоды повторяются по числу единиц. Каждый ТСД удаляет только свои
наблюдения. Повтор запроса после потери ответа защищён идентификатором запроса.

После завершения сканирование закрывается. На ПК доступен CSV: остаток МС,
количество в отгрузках, ожидаемое и фактическое количество, разница. Для ещё
не проверенных брендов разница не выводится как недостача. Сверка не изменяет
остатки МС и не отправляет документы в ЧЗ.

## Обновление

Необходима миграция `20261005_01`, обновление backend/worker/frontend.
Дескриптор и права внешнего решения не меняются. APK 0.1.2 загружает веб-интерфейс
с сервера, поэтому эти режимы доступны в нём после деплоя без переустановки APK.
